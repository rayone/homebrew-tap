# homebrew-tap

Homebrew tap for [rayone](https://github.com/rayone) projects.

## Install

```bash
brew tap rayone/tap
brew install --cask viewr
```

## Casks

| Cask | Description |
|------|-------------|
| `viewr` | [viewR](https://github.com/rayone/viewR) — Native macOS image viewer with parallel decode pipeline |
